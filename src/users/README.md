# Users Module

This module provides functionality for administrators to manage user accounts.

## Features

1. **Create User**: Admin can fill out a form to create a new user.
2. **Edit User**: Admin can update details of an existing user.
3. **Deactivate User**: Admin can mark a user account as inactive.
4. **Delete User**: Admin can permanently remove a user.

## Technical Notes

- Backend logic includes a database schema for user details and department mapping.
- Database table will store activation status and department association.

Further implementation is being developed for this module.
